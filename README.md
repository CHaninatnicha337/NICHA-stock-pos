# 🏪 7-Eleven Style Cloud Architecture: Front Store (POS) & Back Office System

ระบบสต็อกสินค้าและขายหน้าร้านที่ออกแบบตามสถาปัตยกรรมร้านสะดวกซื้อ 7-Eleven โดยแบ่งโครงสร้างอย่างชัดเจนออกเป็น **ระบบหน้าบ้าน (หน้าร้าน POS)** และ **ระบบหลังบ้าน (หลังร้าน Back Office)** ภายใต้ดีไซน์ **Glass Neumorphism (Neumorphism 80% / Liquid Glass 20%) โทนสีขาว-เทา** พร้อมสถาปัตยกรรมฐานข้อมูลกลางซิงค์ข้อมูลร่วมกันแบบเรียลไทม์ระหว่างคอมพิวเตอร์และมือถือ/iPad

---

## 🏛️ การแบ่งแยกระบบหน้าบ้านและระบบหลังบ้าน (Front Store vs Back Office)

ตามแนวคิดสถาปัตยกรรมของ 7-Eleven ระบบถูกแยกการทำงานออกเป็น 2 มุมมองหลัก แต่เชื่อมต่อด้วย **ฐานข้อมูลกลางชุดเดียวกัน (Single Central Database Synced via Python REST API & WebSocket Polling)**:

### 1. 🛒 ระบบหน้าบ้าน / หน้าร้าน (Front Store: POS Terminal)
ออกแบบสำหรับ **พนักงานแคชเชียร์** เพื่อความรวดเร็วและแม่นยำในการให้บริการลูกค้า:
- **Clean & Visual Product Cards**: แสดงรูปภาพสินค้าคมชัด, ชื่อสินค้า, ราคา และปุ่มกดเพิ่ม (+) คลีนตา ไร้ข้อมูลทางเทคนิครกสายตา
- **Smart Stock Alert**: สินค้าที่ใกล้หมดสต็อกจะแสดงกรอบสีแดงแจ้งเตือน (Red Glow Warning) อัตโนมัติโดยไม่ต้องใส่ตัวเลขนับถอยหลังกวนสายตา
- **Quick Category Tabs (Pills)**: แถบเลือกหมวดหมู่ด่วนแนวนอน (ทั้งหมด, เครื่องดื่ม, อาหารพร้อมทาน, เบเกอรี่, ขนม, ของใช้, อาหารแห้ง) แตะสัมผัสง่ายบน iPad/Tablet
- **ระบบพักบิล (Hold Bill / Recall Bill)**: รองรับการพักบิลกรณีลูกค้าขอไปหยิบของเพิ่ม เพื่อคิดเงินให้ลูกค้าคิวถัดไปได้ทันที และกดเรียกคืนบิลเดิมได้ในคลิกเดียว
- **ระบบสรุปปิดกะ (Shift Closing & Cash Drawer Report)**: สรุปยอดขายรวมประจำกะ, แยกประเภทเงินสด, สแกน QR, บัตรเครดิต พร้อมระบบตรวจนับเงินสดในลิ้นชักและคำนวณส่วนต่าง (Over/Short) อัตโนมัติ พร้อมพิมพ์ใบรายงานปิดกะ (Z-Report)
- **สแกนบาร์โค้ด & GS1 DataMatrix**: ค้นหาสินค้าอัตโนมัติพร้อมเสียง "ปี๊บ" แบบเซเว่น
- **ระบบ Expiry Guard**: ตรวจสอบวันหมดอายุตามมาตรฐาน GS1 หากสินค้าหมดอายุ ระบบจะส่งเสียงเตือนและบล็อกการขายทันที
- **คำนวณเงิน Real-time**: แสดงราคาสินค้า, แยกภาษีมูลค่าเพิ่ม (VAT 7% Included) และยอดรวม
- **ชำระเงินครบวงจร**:
  - **Dynamic PromptPay QR**: สร้าง QR Code เจาะจงตามยอดเงินของแต่ละบิล พร้อมจำลอง Webhook ยืนยันการชำระเงินจากธนาคาร
  - **เงินสด (Cash)**: พร้อมแป้นคิดเงินทอนอัตโนมัติ
  - **บัตรเครดิต / EDC**: จำลองการแตะบัตร
- **ระบบตัดสต็อกอัตโนมัติ (Atomic Stock Cut)**: ตัดยอดสต็อกบนชั้นวาง (Shelf) ทันทีที่ชำระเงินสำเร็จ พร้อมออกเลขที่ใบเสร็จ (Receipt ID) และ Transaction ID
- **พิมพ์ใบเสร็จ (Thermal Receipt)**: ใบเสร็จสไตล์ 7-Eleven สั่งพิมพ์ได้ทันที

### 2. 🏢 ระบบหลังบ้าน / หลังร้าน (Back Office: Inventory Management)
ออกแบบสำหรับ **ผู้จัดการร้าน (Store Manager)** และฝ่ายจัดการคลังสินค้า เพื่อควบคุมและบริหารจัดการร้านทั้งหมด:
- **Responsive Navigation**:
  - **บน Desktop (คอมพิวเตอร์)**: เป็น **Sub-Navbar แนวนอน** ด้านบน เลือกคลิกเปลี่ยนแท็บได้ในคลิกเดียว ไม่ต้องเปิด Modal หลายจังหวะ
  - **บน Mobile / iPad**: มีปุ่ม Hamburger สำหรับเปิด **Slide-in Drawer Navigation** ด้านข้างอย่างเป็นระเบียบ ใช้งานง่ายด้วยนิ้วโป้ง
- **1. Dashboard สรุปผล**: ยอดขายรวมประจำวัน, จำนวนบิล, สินค้าใกล้หมด (Reorder Point), สินค้าใกล้หมดอายุ
- **2. Inventory Management**: ตรวจสอบและบริหารสต็อกแยกตาม 4 สถานะจริง:
  - **Shelf**: วางพร้อมขายบนชั้นวางหน้าร้าน
  - **Backroom**: สต็อกสำรองในห้องเก็บของ
  - **Damaged**: สินค้าชำรุดรอเคลม
  - **Expired**: สินค้าหมดอายุรอตัดจำหน่าย
  - พร้อมระบบเพิ่ม/แก้ไขสินค้าที่รองรับการระบุรูปภาพ URL หรือสุ่มรูปสินค้าตัวอย่าง
- **3. Goods Receiving**: บันทึกรับสินค้าเข้าจากการขนส่ง DC ตรวจนับจริง บันทึก Lot/Batch, วันผลิต (MFD) และวันหมดอายุ (EXP)
- **4. Stock Transfer**: ระบบเติมของ โอนสินค้าจากห้องเก็บของ (Backroom) ออกมาจัดเรียงบนชั้นวางหน้าร้าน (Shelf)
- **5. Stock Counting & Approval**: ระบบตรวจนับสต็อกจริงเทียบกับในระบบ พร้อมปุ่มขออนุมัติจากผู้จัดการร้าน ป้องกันพนักงานแก้ตัวเลขโดยพลการ
- **6. Expiry Management (FEFO)**: จัดการวันหมดอายุตามหลัก First Expired, First Out และปุ่มตัดจำหน่าย (Write-off)
- **7. Movements Ledger**: บันทึกประวัติความเคลื่อนไหวทุกรายการ (SALE, RECEIVE, TRANSFER, ADJUST, EXPIRED)
- **8. Audit Log**: บันทึกกิจกรรมและความปลอดภัยเพื่อความโปร่งใสและตรวจสอบการทุจริต

### 🔒 ระบบรักษาความปลอดภัยและการสลับบทบาท (Role & Security)
- มีปุ่มสลับโหมดหลัก **[หน้าร้าน (Front POS)]** และ **[หลังร้าน (Back Office)]** ด้านบนสุด
- มีปุ่มสลับบทบาทพนักงานระหว่าง **ผู้จัดการสาขา (Store Manager)** และ **พนักงานแคชเชียร์ (Cashier)**
- หากผู้ใช้งานในบทบาทแคชเชียร์พยายามเข้าสู่ระบบหลังร้าน ระบบจะเรียกถาม **รหัส PIN ผู้จัดการร้าน (Default PIN: 1234)** เพื่อความปลอดภัยตามมาตรฐาน 7-Eleven

---

### 🌐 ระบบฐานข้อมูลกลางซิงค์ข้ามอุปกรณ์ (Single Central Database Synced)
- รันเซิร์ฟเวอร์ด้วย `python server.py` (หรือดับเบิ้ลคลิก `run.bat`)
- เซิร์ฟเวอร์ทำหน้าที่เป็น REST API ให้บริการ endpoint `/api/data`, `/api/sync`, `/api/reset`
- เมื่อแคชเชียร์ขายสินค้าบนคอมพิวเตอร์ ข้อมูลสต็อกในมือถือหรือ iPad ที่ต่อ Wi-Fi เดียวกันจะซิงค์และตัดสต็อกชุดเดียวกันโดยอัตโนมัติ

## 🎨 การออกแบบ Glass Neumorphism (Neu 80% / Glass 20%)
- **Neumorphism 80%**: โครงสร้างหลัก พื้นผิวแผง คอนโซล แป้นตัวเลข และปุ่มกดนุ่มนวล โทนสีขาว-เทา (`#ebf0f7` / `#ffffff` / `#c8d0de`) พร้อมแสงเงาสองด้านแบบสมจริง
- **Liquid Glass 20%**: ป็อปอัปชำระเงิน Dynamic QR Code, สลิปใบเสร็จ, ป้ายสถานะ Liquid Pill ใส ขอบสะท้อนแสงมันวาว (Liquid Specular Gradient Border) และกระจกฝ้า (`backdrop-filter: blur(24px)`)
